Sketchbook Planning Poker - User Guide

App: Planning Poker for Jira Cloud   Provider: Aioomi

Support: aioomi_at_support@aioomi.com

What it is

Planning Poker is a real-time estimation tool for Jira Cloud. Your team votes on story points with cards, reveals together, and the app writes the agreed estimate back to the Jira issue. Its distinctive feature is per-team estimation: split the room into subgroups so each team estimates its own part of the work, and the results are summed into one honest total.

Getting started

  1. Open Planning Poker from the Jira Apps menu in the top navigation, or from the Planning Poker panel on any Jira issue.
  2. On first use, open Settings (the gear icon) to pick your hand-drawn character and your display name. Both are optional.

Creating a room

  1. In the lobby, type a room name and click Create room.
  2. You become the room host, marked with a star. The host controls the round.

Setting up the room

In room setup you can configure:

  • Card deck: the values people vote with. Numbers count toward the average; special cards such as "?" and coffee have no value.
  • Subgroups (teams): add teams such as Front-end, Back-end, and QA. Leave this empty for one shared group.
  • Issue queue: search your Jira issues by key or name and add the ones you want to estimate.
  • Where to save results: post a comment on the issue and/or write the total to a numeric field (Story Points by default).

Running a round

  1. The host clicks Start estimation.
  2. Everyone picks a card. Votes stay hidden.
  3. The host clicks Reveal cards.
  4. Each team's average is shown, and the team averages are summed into one total for the issue.
  5. The host clicks Write to Jira to save the result and move to the next issue.

Per-team estimation

When you use subgroups, each member votes only for their own team. The app averages each team's votes, then sums the team averages into a single total for the issue. Special cards with no value are excluded from the average.

Who votes this round

With two or more teams, the host can choose who votes: everyone, or a specific team.

Round history

Every finished round is saved per room. Open History to see who voted what, grouped by team, together with the totals.

Languages

The interface is available in English and Polish. Switch languages with the language buttons in the top bar.

Privacy and data

The app runs entirely on Atlassian and does not use external servers. See the privacy policy for details.
